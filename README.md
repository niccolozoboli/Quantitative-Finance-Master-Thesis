# Quantitative Finance Master Thesis

This repository contains the code and experiments developed for my
Master’s thesis in Data Science.

The project focuses on forecasting financial and commodity price
time series using a comparative approach that includes:
- traditional statistical models
- Machine Learning methods
- Deep Learning architectures

## Objectives
- Build reliable forecasting pipelines for time series data
- Compare classical models (e.g. ARIMA) with ML and DL approaches
- Evaluate models using standard forecasting error metrics

## Methodology
1. Data collection and preprocessing
2. Exploratory data analysis and feature engineering
3. Baseline statistical models
4. Machine Learning models
5. Deep Learning models
6. Model comparison and discussion

## Technologies
- Python
- NumPy, Pandas
- scikit-learn
- statsmodels
- PyTorch
